About

I studied geophysics, then started in software in 2018 on Extreme Programming teams: pair programming, the test written first, small slices shipped continuously. Most of how I work still comes from there.

I work across the stack: React, Next.js and React Native in the product, Rails and Node.js services behind it, and the AWS platform and databases underneath. The last few years leaned toward the platform half: autoscaling, database load and LLM provider failover.

I like owning a system from the architecture decision to the incident review. When production breaks, I write down what is verified and what is only inferred before I change anything. The write-ups on this site come out of that habit.
